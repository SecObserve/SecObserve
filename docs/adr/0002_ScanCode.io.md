# Integration of ScanCode.io

## Context

ScanCode performs deep codebase analysis to identify dependencies, licenses, and copyrights, while ScanCode.io provides a Web UI and API for ScanCode to run and review complex scans in rich scripted pipelines, on different kinds of containers, docker images, package archives, manifests etc.

## Considered options

SecObserve can already import SBOMs in CycloneDX and SPDX format generated by various scanners, but with the ScanCode.io integration deeper insights into components and their licenses and copyrights can be achieved.

## Decision

The integration of SecObserve with ScanCode.io consists of:

- Integrated Docker Compose setup including all components of SecObserve and ScanCode.io for development.
- Calling the ScanCode API to setup a product in ScanCode, start a scan and being notified about the finishing of a pipeline.
- Extension of the data model to store more information coming from ScanCode and amendmend of the API integration to read the results and store them in SecObserve.
- Evaluation and enhancement of the out-of-the-box pipelines of ScanCode to let them work more optimised for SecObserve to achieve a maximum of information.
- Storing more attributes about existing licenses like license conditions, URLs, owners etc. to give users more information to properly evaluate license compliance.
- A spike to see if an instance of PurlDB helps to get better information.
- Install instructions for a productive setup for separated instances of SecObserve and ScanCode.io, to be more flexibel, e.g. for separate update schedules.
