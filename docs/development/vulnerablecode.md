# VulnerableCode

## Starting the server

To have a close integration between SecObserve and [VulnerableCode](https://vulnerablecode.readthedocs.io), the script

```bash
./bin/vulnerablecode_dev.sh
```

starts both SecObserve and VulnerableCode in one Docker Compose environment. The VulnerableCode UI can then be accessed with [http://localhost:4000/](http://localhost:4000/).
